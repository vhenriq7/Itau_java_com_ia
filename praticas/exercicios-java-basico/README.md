## Como trabalhar

1. Acesse o README da etapa e abra o **enunciado original** antes de começar.
2. Quando iniciar uma atividade, crie dentro do módulo a pasta indicada, por exemplo `01-fundamentos-java/01-idade/`.
3. Desenvolva **seu próprio código Java** nessa pasta. Adicione um README curto explicando como compilar/executar e o que aprendeu, quando fizer sentido.
4. Após testar, altere `[ ]` para `[x]` no checklist do módulo e atualize o acompanhamento geral.
5. Faça commits vinculados ao trabalho real (`feat:`, `fix:`, `refactor:`, `docs:`).

**Importante:** esta organização contém resumos e referências aos materiais oficiais, **não contém soluções prontas**. Os requisitos completos de cada atividade devem ser consultados diretamente no repositório da DIO. Os exercícios concluídos serão trabalho autoral e ficarão fora de `ferramentas/dio-agent`.
