## Objetivo

Criar uma calculadora de terminal com menu repetitivo e operações matemáticas.

**Tecnologias previstas:** Java (console).

## Checklist de implementação

- [ ] Exibir menu numérico e repeti-lo após cada operação até selecionar **Sair**.
- [ ] Implementar soma e subtração.
- [ ] Implementar multiplicação e divisão (com tratamento adequado para números decimais e divisão por zero).
- [ ] Implementar potência de um número elevado a N.
- [ ] Testar entradas e resultados das operações.

## Extras opcionais

- [ ] Criar submenu para continuar somando/subtraindo novos números ao resultado atual ou voltar ao menu principal.
