Cada projeto tem seu próprio `README.md` com o link ao enunciado completo, checklist de requisitos e extras opcionais. O código será criado **pelo estudante**, nesta pasta correspondente, conforme o desenvolvimento avançar.

## Fluxo de trabalho

1. Escolha um projeto e abra seu enunciado original da DIO.
2. Planeje pequenos incrementos e implemente as funcionalidades uma a uma.
3. Inclua testes adequados, instruções de execução e decisões relevantes no README do projeto.
4. Marque as tarefas efetivamente concluídas no checklist.
5. Faça commits significativos à medida que o código evoluir (não apenas para gerar atividade).

**Distinção:** os 20 exercícios menores da DIO estão organizados separadamente em [praticas/exercicios-java-basico](../praticas/exercicios-java-basico/README.md). Os [desafios independentes](../desafios/README.md) serão registrados quando forem divulgados pela trilha.
