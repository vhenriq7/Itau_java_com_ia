## Objetivo

Implementar um jogo de Sudoku, usando argumentos do método `main` para receber o tabuleiro inicial.

**Tecnologias previstas:** Java; estruturas de dados e orientação a objetos.

## Checklist de implementação

- [ ] Carregar números e posições iniciais por `args` e exibir o tabuleiro.
- [ ] Implementar menu: iniciar jogo, adicionar número, remover número e visualizar tabuleiro.
- [ ] Impedir edição ou remoção dos números fixos e ocupação indevida de uma posição já preenchida.
- [ ] Verificar estado do jogo (não iniciado, incompleto ou completo) e conflitos no tabuleiro.
- [ ] Permitir limpar as jogadas sem remover números fixos.
- [ ] Finalizar somente quando todos os espaços estiverem preenchidos corretamente.

## Extras opcionais

- [ ] Adicionar interface gráfica com AWT ou Swing.
- [ ] Permitir anotações de rascunho nas células.
